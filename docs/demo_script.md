# Demo script

1. Order `ORD_001` needs **150** Battery Cells at the Bangalore plant.
2. ERP reports **500** usable units; the warehouse reports **120**.
3. The trust contract allows a maximum 5% variance. Actual variance is **76%**, so the status is **CONFLICTED**.
4. A normal chatbot that trusts ERP would say "fulfill the order". This system refuses to give a confident answer.
5. Show the evidence trail: both source records, their systems, values and timestamps.
